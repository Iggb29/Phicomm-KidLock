ZenScreen · 醒来 (TV 注意力与健康守护系统)

“屏幕不应是吞噬时间的黑洞，而是通往好奇心与现实生活的跳板。”
ZenScreen 是专为 Android 电视盒子（如斐讯 T1、外贸盒子、智能电视）打造的开源注意力与健康管理系统。它打破了传统防沉迷“暴力掐断与惩罚服刑”的旧逻辑，重构为**“时段感知 + 时间银行 + 好奇心挑战”**的正向激励机制。
🌟 核心特性
时间银行（Time Wallet）：
孩子可在看电视前主动发起挑战，连续答对 3 道题即可向“时间银行”充入 30 分钟娱乐燃料，将“被监控”变为“凭智力赢取资产”。
夜间成人免打扰（Curfew Rule）：
默认设定 21:00 ~ 次日 07:00 自动隐形。此时间段电视归成年人专属，守护系统彻底休眠，绝不弹窗打扰观影。
零编译热插拔（Hot-Plug Content）：
题库与配置文件与 APK 完全解耦。无需重新打包软件，只需将新的题目文件放入电视存储，即刻生效。
底层硬件守护（Root Watchdog）：
基于 Root / 前台看门狗机制，拦截遥控器返回键逃逸与 Home 键切后台，确保护眼休息真正落实。
家长后门通道：
任意时刻连按 4 次遥控器【菜单键（Menu）】，输入默认 PIN 码 8888 即可快速放行 2 小时。
